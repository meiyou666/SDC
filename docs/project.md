# 项目研究说明

依据正式申请书《面向低精度矩阵乘法的算法级容错评测与优化》整理。研究目标、方法和实验口径调整时，同步更新本文与 `AGENTS.md` 中的项目摘要。

## 研究问题

SDC 可能使矩阵乘法产生错误结果，而训练仍继续执行。ABFT 利用矩阵计算的代数关系生成校验冗余，在正常执行过程中检测错误，并通过定位纠正或重算恢复结果。

低精度带来两方面变化：FP8、FP4 的低位翻转也可能造成明显的数值扰动；主计算与校验计算的正常误差会进入校验残差，影响故障判定。提高校验精度可以减少校验自身的舍入误差，主 GEMM 的误差仍需处理。项目围绕正常误差、故障响应和阈值的关系，研究兼顾检出率、误报率与开销的 ABFT 方法。

## 三项研究内容

| 内容 | 主要任务 | 交付 |
| --- | --- | --- |
| 统一评测 | 在真实训练操作数上比较代表方法，统一故障注入、统计与计时，解释方法差异 | 基线实现、评测框架、事件数据和分析报告 |
| 低精度算法优化 | 分解主计算、参考校验和输出归约误差，研究校验组织、累加路径与判定机制 | 新方法、基线比较和消融结果 |
| 昇腾算子融合 | 将校验生成、传播、判定与恢复融入量化 GEMM，复用片上数据 | CANN / Ascend C 算子、训练集成与性能结果 |

统一评测与算法研究可以并行开展，复用同一输入、故障协议与指标。算法设计根据论文复现和实验分析逐步确定。

## 代表方法

| 方法 | 比较的核心机制 |
| --- | --- |
| [经典 ABFT](https://doi.org/10.1109/TC.1984.1676475) | 全 1 与递增加权校验，单元素错误定位与纠正；[带权校验研究](https://doi.org/10.1117/12.944013) |
| [GVFA](https://doi.org/10.1515/mcma-2020-2076) | 高斯随机投影与重复验证 |
| [V-ABFT](https://arxiv.org/abs/2602.08043v1) | 正常残差建模与自适应阈值 |
| [Strided ABFT](https://doi.org/10.1145/3712285.3759853) | FT-Transformer 中的分组编码、局部归约及其执行组织 |
| [AEGIS 校验](https://www.usenix.org/conference/osdi26/presentation/lei) | FP32 累加结果取数与历史残差阈值 |

完整方法比较保留各自的编码、阈值、检查位置和状态更新。单因素实验每次改变一个机制。Strided ABFT 和 AEGIS 选取上述 GEMM 校验机制，在 NPU 上组织实现。

复现先精读原文，标明公式、算法与代码的对应位置，再进行小规模验证。核心机制经人工比对后扩大实验。论文精读放在 `docs/papers/`，实现与核对记录放在 `docs/reproduction/`。

## 共同实验口径

**任务与精度。** 以 Qwen3-0.6B 全参数继续预训练中的单次 GEMM 为比较单位。重点采集前向线性层，补充输入梯度与权重梯度，覆盖不同层、序列长度和训练阶段。研究 FP8、FP4，以 BF16、FP32 为对照；记录输入码值、尺度、实际乘加与累加方式、转换位置及输出精度。

**正常参考。** 令量化码值与尺度确定的逻辑输入为 $A_q,B_q$，使用其高精度乘积 $C_q^*=A_qB_q$ 分析数值误差。输入量化近似单独统计。校验残差统一写为 $r=c^{obs}-c^{pred}$，分别分析主计算、校验生成与传播、输出归约的贡献。分块缩放时，校验随实际码值、尺度和计算顺序组织。

**故障注入。** 每个事件翻转一个元素的一位，遍历各格式的编码位。参考校验保留后，对实际低精度操作数或导出的 FP32 块部分和进行异或注入，并记录坐标、位类型、方向和时刻。零掩码对照保留同样的读写与同步。输入单元素故障可能传播到多个输出元素，需记录实际受损范围。

**比较与校准。** 方法间共享训练操作数与配对故障。正常、校准和测试数据按文档划分；阈值使用独立正常样本校准。有状态方法从相同的正常历史状态开始。改变累加路径时，分别建立正常参考，测量输出与数值行为的变化。

| 指标 | 统一口径 |
| --- | --- |
| 调用误报率 | 正常调用中任一校验报警的调用数 / 正常调用数 |
| 受损事件检出率 | 输出受损且报警的事件数 / 输出受损事件数；共同有限受损事件另行配对比较 |
| 定位与恢复 | 正确定位或逐位恢复且复检通过的次数 / 单输出元素受损事件数；两项分别统计 |
| 误恢复率 | 复检通过但输出仍错误的恢复次数 / 实际触发恢复次数；正常组与故障组分别统计 |
| 输出影响 | 故障相对配对正常输出的变化，以及相对有效输入高精度乘积的误差 |
| 保护开销 | 完整设备端时间，同时相对同源无保护内核和原生库 GEMM 报告 |

检测计时包括量化、主计算、参考校验生成、校验乘法与传播、输出归约、比较、必要状态更新和同步。定位、修复与复检另测故障路径。使用设备事件计时，Python 调度、初始主机传输与离线诊断单独处理。融合收益在相同算法和保护配置下比较。

核心低精度配置的正常调用、操作数故障和累加结果故障各按不少于 $10^5$ 次设计。先完成小规模验证，再扩大规模；保留输出未变及非有限事件，报告统计分母与 95% 置信区间。
