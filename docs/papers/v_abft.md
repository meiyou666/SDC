# V-ABFT: Variance-Based Adaptive Threshold for Fault-Tolerant Matrix Multiplication in Mixed-Precision Deep Learning

- 出处与链接：Yiheng Gao、Qin Hua、Zizhong Chen，arXiv:2602.08043v1，2026-02-08。[论文 PDF](https://arxiv.org/pdf/2602.08043v1)、[HTML](https://arxiv.org/html/2602.08043v1)。以下式号、算法行号均以 v1 为准。
- 解决的问题：正常浮点计算也会产生 ABFT 校验残差。V-ABFT 直接建模两条校验路径的差，用输入行统计量和平台误差系数计算逐行阈值。
- 本项目要用的机制：式 (23) 的残差阈值、式 (24) 的方差上界、式 (25) 的正常样本标定。检查位置须区分低精度输出写回后与 FP32 累加器量化前。

## 核心公式与算法

### 1. 检查对象与符号

设输入 A 的形状为 `[M,K]`，B 为 `[K,N]`，输出 C 为 `[M,N]`。下标 m 表示 A/C 的行，k 表示归约维，n 表示输出列。本文只展开全 1 行校验的阈值；加权校验用于定位，不能直接认为它使用同一阈值。

| 论文位置 | 内容 | 说明 |
|---|---|---|
| 式 (1)–(3) | 全 1 向量编码 B 的行和，再通过 A 传播 | 得到参考行校验；论文同时给出递增加权和列校验 |
| 式 (4)、(11) | 输出行和与参考行校验相减 | 式 (11) 的符号是“参考减观测”；本项目的残差符号相反，绝对值判定相同 |
| 式 (5) | 残差绝对值严格超过逐行阈值时报警 | 相等不报警 |
| 式 (13)–(14)、(18) | 两条计算路径的舍入误差差异及其系数 | 引出平台误差系数；在线算法不逐元素估计这些系数 |
| 式 (15)–(23) | 均值、随机波动和交互项展开 | 得到三项相加的阈值 |
| 式 (24)；Alg. 1 第 1–6 行 | 用行最大值、最小值、均值估计方差上界 | 不需要逐元素平方差 |
| 式 (23)；Alg. 1 第 7–10 行 | 计算确定项、两项合并方差、交互项，再乘误差系数 | 完整公式见下文 |
| 式 (25)；§3.6 标定协议第 1–3 步 | 正常残差相对参考校验的最大比值，另加 20% 裕量 | 新平台建议 100,000 次正常试验 |
| §5.2 第 1–3 步（无算法行号） | 块内统计、块内阈值、汇总块校验和 | 未给出最终汇总阈值的公式 |

用 `fl` 表示实际浮点路径。将式 (2)–(5)、(11)、(13) 写成实现所需的两个向量：

$$
b_k^{sum}=\operatorname{fl}\!\left(\sum_{n=0}^{N-1}B_{kn}\right),\quad
p_m=\operatorname{fl}\!\left(\sum_{k=0}^{K-1}A_{mk}b_k^{sum}\right),\quad
o_m=\operatorname{fl}\!\left(\sum_{n=0}^{N-1}C_{mn}\right).
\qquad\text{[式 (2)–(4)、(13) 的展开]}
$$

$$
E_m=p_m-o_m,\qquad \mathrm{alarm}_m=(|E_m|>T_m).
\qquad\text{[式 (11)、(5)]}
$$

p、o 都是 `[M]`。参考路径必须保留独立计算的校验信息，不能直接用 C 的行和充当 p。这里的等式说明路径，未规定每个 `fl` 的 dtype 和归约树；标定时必须使用待部署的实际路径。

### 2. 完整阈值及每个量的来源

论文先使用真实行标准差推导式 (23)，再在 Alg. 1 中用方差上界替换。下面用 v 区分“方差上界”和真实方差，避免把极值估计写成精确方差。

$$
\begin{aligned}
\mu_{A_m}&=\operatorname{mean}_k A_{mk},&
v_{A_m}&=(\max_k A_{mk}-\mu_{A_m})(\mu_{A_m}-\min_k A_{mk}),\\
\mu_{B_k}&=\operatorname{mean}_n B_{kn},&
v_{B_k}&=(\max_n B_{kn}-\mu_{B_k})(\mu_{B_k}-\min_n B_{kn}).
\end{aligned}
\quad\text{[式 (24)；Alg. 1 第 1–6 行]}
$$

式 (24) 给出真实总体方差不超过对应 v。这里的最大值、最小值保留符号，不是绝对值的极值。A 沿 K 取统计量，B 沿 N 取统计量。

把 B 的各行统计量归约为三个可复用标量：

$$
S_{|\mu|}=\sum_{k=0}^{K-1}|\mu_{B_k}|,\qquad
S_{\mu^2}=\sum_{k=0}^{K-1}\mu_{B_k}^2,\qquad
S_v=\sum_{k=0}^{K-1}v_{B_k}.
\quad\text{[Alg. 1 第 7–9 行的中间量记法]}
$$

最终可实现的阈值为：

$$
\boxed{
T_m=e_{\max}\left[
N|\mu_{A_m}|S_{|\mu|}
+c_\sigma\sqrt{N\mu_{A_m}^{2}S_v+N^2v_{A_m}S_{\mu^2}}
+c_\sigma\sqrt{N}\sqrt{v_{A_m}}\sqrt{S_v}
\right].}
\quad\text{[式 (23) 代入式 (24)；Alg. 1 第 7–10 行]}
$$

| 量 | 来源与形状 | 用在哪里 |
|---|---|---|
| A 的行最大值、最小值 | 当前输入；各 `[M]` | 只用于构造 v_A |
| A 的行均值 | 当前输入；`[M]` | 确定项、第二项中的均值平方，以及 v_A |
| B 的行最大值、最小值 | 当前输入；各 `[K]` | 只用于构造 v_B |
| B 的行均值 | 当前输入；`[K]` | 绝对值和、平方和，以及 v_B |
| 三个 S | B 的行统计量；各标量 | 同一 B 对应的所有 A 行共享 |
| N | B/C 的列数；整数标量 | 决定显式的 N、N²、平方根因子 |
| K | A 的列数/B 的行数；整数标量 | 决定 A 的均值归约范围和三个 S 的求和范围 |
| M | A/C 的行数；整数标量 | 决定阈值数量，不直接乘入单行阈值 |
| e_max | 平台、计算路径和精度配置的标定参数；浮点标量 | 最后乘在三项之和上；可能依赖尺寸 |
| c_sigma | 人为选择的置信系数；浮点标量 | 乘在两个随机项上；论文取 2.5 |

第一项对应式 (21) 的均值偏置。第二项把 A 波动与 B 波动两项的方差相加后开方。第三项对应两者波动的交互作用。因此不能把三个阈值项全放进一个平方根，也不能遗漏第二项中的 N²。

误差系数在推导中的定义是：

$$
\alpha_k=\frac{1}{N}\sum_n e_{kn},\qquad
\beta_k=\sqrt{\frac{1}{N}\sum_n e_{kn}^2},\qquad
e_{\max}\ge\max_k\{|\alpha_k|,|\beta_k|\}.
\quad\text{[式 (18)；式 (23) 前的定义]}
$$

e_kn 表示式 (14) 中两条路径的有效误差差异。实际算法通过正常运行标定 e_max，不读取 e_kn、alpha 或 beta。§3.4 使用随机项的独立性和方差相加，c_sigma=2.5 的约 99% 覆盖解释依赖高斯假设。它不是整次 GEMM 零误报的理论保证。

### 3. 分块统计与最终判定

§5.2 给出的典型块形状是 `(M_b,K_b,N_b)=(128,1024,256)`。对参与一次块乘法的 A 块 `[M_b,K_b]` 和 B 块 `[K_b,N_b]`，直接将 Alg. 1 的 M、K、N 替换为对应块尺寸：

| 块内信息 | 提取方向及形状 | 后续用途 |
|---|---|---|
| A 块每行 max、min、mean | 沿 K_b；各 `[M_b]` | 计算该块各行的均值和 v_A |
| B 块每行 max、min、mean | 沿 N_b；各 `[K_b]` | 计算该块各行的均值和 v_B，再生成三个 S |
| B 块行校验和 | 沿 N_b；`[K_b]` | 通过 A 块传播，得到参考校验 `[M_b]` |
| 输出块行和 | 沿 N_b；`[M_b]` | 与对应参考校验形成残差 |
| 块内阈值 | 使用块尺寸与对应路径的 e_max；`[M_b]` | 对应块内各行的误差判定 |

前三种统计量服务于阈值，校验和服务于残差。代数上均值乘行长度可恢复行和，但浮点下运算顺序不同；论文未说明是否复用同一次归约结果，不能擅自替换参考校验路径。

**论文能确定的流程到“汇总块校验和”结束，未给出可直接复现的跨块最终判定算法。** §5.2 只列出三个步骤：提取每块行统计量、逐块使用阈值公式、汇总块校验和用于最终验证。

下列两种组织方式都需要更多信息，不能混为论文实现：

- 若各块各自检查，再把报警标志做 OR，需要确认论文是否采用这种组织；原文没有给出。
- 若先将多个块的校验和相加，再计算一个最终残差，需要说明跨 K 分块的部分积累加、跨 N 分块的行和合并，以及最终阈值怎样组合。原文没有给出阈值相加、方差相加或重新计算全局阈值的选择，也没有给出汇总舍入误差项。

因此，下方伪代码完整实现单个检查域的阈值。检查域可以是完整矩阵或单个块；跨块汇总保持为待确认接口，不补造公式。

## 伪代码

**dtype 约定：** Alg. 1 没有规定统计量和阈值的 dtype。为使实现接口明确，本笔记将阈值参考计算统一规定为 FP64；这是笔记的实现约定，不是论文声称的融合内核精度。输入保留目标格式已表示的数值，转 FP64 仅用于统计，不替换实际 GEMM/校验路径。FP8 输入须先明确格式与尺度解码，论文未给出这部分实现。

```text
函数 THRESHOLD(A, B, e_max, c_sigma=2.5)
输入：
  A: [M,K], dtype D_in；B: [K,N], dtype D_in
     D_in 为 BF16 / FP16 / FP32 / FP64；本接口要求有限值和正尺寸
  e_max: [], FP64，当前平台、检查位置、路径、尺寸所用的已标定系数
  c_sigma: [], FP64，默认 2.5
输出：
  T: [M], FP64，每行的绝对残差阈值
步骤：
  X = cast_fp64(A)                          # [M,K]，下列归约均为 FP64
  Y = cast_fp64(B)                          # [K,N]
  mu_A = mean(X, axis=1)                    # [M]；Alg. 1 行 1
  hi_A = max(X, axis=1); lo_A = min(X, axis=1)
  v_A = (hi_A - mu_A) * (mu_A - lo_A)        # [M]；Alg. 1 行 2 / 式 (24)
  mu_B = mean(Y, axis=1)                    # [K]；Alg. 1 行 3–4
  hi_B = max(Y, axis=1); lo_B = min(Y, axis=1)
  v_B = (hi_B - mu_B) * (mu_B - lo_B)        # [K]；Alg. 1 行 5–6 / 式 (24)

  S_abs = sum(abs(mu_B))                    # []；Alg. 1 行 7
  S_mu2 = sum(mu_B * mu_B)                  # []；Alg. 1 行 8
  S_v   = sum(v_B)                          # []；Alg. 1 行 8–9
  n = cast_fp64(N)                          # 先转浮点再平方，避免整数溢出
  det   = n * abs(mu_A) * S_abs              # [M]；Alg. 1 行 7
  var23 = c_sigma * sqrt(n * mu_A**2 * S_v
                         + n**2 * v_A * S_mu2)  # [M]；Alg. 1 行 8
  var4  = c_sigma * sqrt(n) * sqrt(v_A) * sqrt(S_v)
                                             # [M]；Alg. 1 行 9
  T = e_max * (det + var23 + var4)           # [M]；Alg. 1 行 10
  return T

函数 CHECK_ONE_DOMAIN(p, o, T)
输入：
  p: [M], dtype D_pred，实际参考路径得到的行校验
  o: [M], dtype D_obs，实际输出路径得到的行和
  T: [M], FP64
  D_pred、D_obs 为该路径配置的浮点 dtype，必须与标定一致
输出：
  residual: [M], FP64
  row_alarm: [M], bool
步骤：
  residual = cast_fp64(p) - cast_fp64(o)    # 式 (11)，减法精度为本笔记约定
  row_alarm = abs(residual) > T            # 式 (5)
  return residual, row_alarm
```

上述检查函数规定在 FP64 做最终相减。若设备内核使用其他减法精度，须改用实际路径并重新标定，不能认为两者数值行为相同。非有限值、溢出或因舍入产生负 v 的处理未见于 Alg. 1，伪代码不悄悄加入裁剪或 epsilon；部署前需另行约定。

## 复现要点

### 输入统计量与参数

- 需要的输入统计量：每个检查域内 A、B 的逐行有符号 max、min、mean；B 的三个归约标量可复用。常数行的极差为零，因此其 v 为零，仍需保留含均值的阈值项。[式 (24)；Alg. 1 第 1–9 行]
- 超参数与取值：c_sigma 取 2.5；e_max 按实际平台和路径标定。c_sigma 是置信倍率，e_max 是误差尺度，二者来源不同。[§3.4、§3.6]
- 阈值或判定条件：逐行比较残差绝对值与 T，使用严格大于。正常样本的最大比值用于设置 e_max，在线每次调用仍通过输入统计量计算 T。[式 (5)、(23)、(25)]

### 标定步骤与正常样本数量

式 (25) 的定义及 §3.6 的部署裕量可分别写为：

$$
e_{\max}^{obs}=\max\frac{|E|}{|\mathrm{checksum}|},\qquad
e_{\max}^{deploy}=1.2\,e_{\max}^{obs}.
\quad\text{[式 (25)；§3.6 标定协议第 3 步，无独立式号]}
$$

分母是参考路径的 checksum，不是式 (23) 的阈值，也不是输出矩阵的范数。对本笔记的全 1 行校验，对应前文 p；论文写作 `checksum = A·B^r`，未明确式 (25) 取哪些编码列，见末尾。

1. 固定硬件、GEMM/校验实现、输入与累加 dtype、输出 dtype、检查位置和代表尺寸。标定应复现同一组计算路径。
2. 按 §3.6 第 1 步生成元素来自绝对值正态分布的正矩阵，即先采样均值 1、方差 1 的正态变量，再逐元素取绝对值。正输入用于减少分母因正负抵消而接近零的问题。
3. 在无故障条件下执行主计算与两条校验路径，记录式 (25) 的比值，取观测最大值。§3.6 第 2 步建议在代表尺寸上做 **100,000 次正常试验**。
4. 将最大值增加 **20% 裕量** 后作为部署参数。[§3.6 第 3 步]

论文没有明确 100,000 次是每个代表尺寸各做一次，还是所有尺寸合计；也未定义一次 trial 包含多少矩阵、多少行比值。不能将它改写成“只需 100,000 行”。§3.6 的已有测量另写了 NPU 每配置 2,000 次、CPU/GPU 每尺寸 500–2,000 次，这些是参数测量的实验数量，不应替代部署建议。

可执行的标定循环仍需先确定 trial 与编码列的口径。以下只展示**本笔记选定的全 1 行校验口径**，不是补称论文已有的算法：

```text
输入：
  normal_trials: Q 次无故障实际路径输出
    每次提供 p:[M_q], D_pred 和 o:[M_q], D_obs
    操作数按 §3.6 第 1 步采样，尺寸与 dtype 配置由调用者确定
  Q: 整数；论文建议 100000，但多尺寸的样本分配未说明
输出：e_max_deploy: [], FP64
步骤：
  peak = FP64(0)
  for (p, o) in normal_trials:
    p64 = cast_fp64(p); o64 = cast_fp64(o)
    要求 p64、o64 有限且每个 abs(p64) > 0；否则报告未定义情况
    ratios = abs(p64 - o64) / abs(p64)       # [M_q], FP64；式 (25)
    peak = max(peak, max(ratios))            # 式 (25)；逐行取最大为本笔记口径
  return FP64(1.2) * peak                   # §3.6 标定协议第 3 步
```

### 论文的实验设置

§6.1 使用 Ascend 910B/CANN 8.2、H100/CUDA 12.0、Xeon/PyTorch 2.1。输入包括近零均值正态、均值为 1 的正态、[-1,1] 均匀分布和截断正态。Table 4 的 FP64 阈值紧度实验为 20 次，使用 100 位十进制精度参考；Table 5 的 FP32 和 Table 6 的 BF16 各为 100 次。它们与前述标定试验数量分别记录。

## 不确定的地方

1. **跨块汇总不完整。** §5.2 没有定义分块轴、块校验和汇总顺序、跨块阈值组合、额外舍入项，也未说明最终报警是否为块报警的 OR。无法仅凭 v1 写出唯一的最终分块判定实现。
2. **标定样本单位不明确。** §3.6 的 100,000 trials 没有明确是每尺寸还是合计，也没有给出 trial 内矩阵和行比值的数量、随机种子及拟合过程。
3. **式 (25) 的最大值范围不明确。** `checksum=A·B^r` 按式 (2) 包括原矩阵列和两个编码列，而 E 是行校验差。未说明参与比值的是全 1 校验、加权校验还是两者，以及矩阵、行和尺寸之间如何取最大。零分母、非有限值也无处理说明。
4. **经验系数与推导上界之间缺少论证。** 式 (23) 要求 e_max 覆盖 alpha、beta；式 (25) 是聚合残差相对校验和的经验比值。论文没有证明有限样本的后者加 20% 就满足前者，也没有给出任意输入的误报概率保证。
5. **N/K 记号冲突。** Table 1、Table 7 的 Ascend FP32 推荐式使用 N，§3.6 标定协议后的参考值使用 K。CPU/GPU 的尺寸测量是方阵，不能据此判定矩形块应代入哪一个维度；本笔记不替作者选择。
6. **H100 BF16 推荐值冲突。** §3.6 标定协议后的参考值把 BF16/FP16/FP8 一起写为 10⁻³，Table 7 则把 BF16 写为 8×10⁻³。文中还有统一 FP16 输出的条件讨论，但未明确该处是否切换了 BF16 输出路径，不能直接消解差异。
7. **拟合值与推荐值不同。** §3.6 的 H100 FP32/FP64 拟合系数与 Table 7 的推荐系数不同；正文提到 20% 裕量，但未逐项说明 Table 7 如何由拟合值变换得到。本笔记保留 Table 7 推荐值，不混用两组参数。
8. **式 (24) 的证明有中间步骤问题。** §3.5 从凸性弦线界写到每个元素的平方偏差都不超过同一个均值相关乘积，这一步一般不成立；需要对弦线界取平均才能得到方差界。式 (24) 的方差界与 Alg. 1 可区分处理，不能照抄该逐元素推断。
9. **数值执行细节缺失。** Alg. 1 未指定统计量、阈值、校验归约的 dtype、归约树、极值误差处理和非有限值策略。本笔记的 FP64 接口是明确的参考实现约定，不能当作论文实际内核配置。加权/列校验的独立阈值与 FP8 尺度处理也未在 Alg. 1 中展开。
