# Gaussian variant of Freivalds’ algorithm for efficient and reliable matrix product verification

- 出处与链接：Monte Carlo Methods Appl. 2020; 26(4): 273–284 https://doi.org/10.1515/mcma-2020-2076
- 解决的问题：改善了两种传统方法在错误检测可靠性上的局限：Huang–Abraham 算法存在固定的检测盲区，某些错误会保持行、列校验和不变[p4, "However,..."]，因而漏检；Freivalds 算法虽然通过随机投影避免了这类固定盲区，但单轮仍有概率漏检，其最坏情形上界为 $1/2$，需要独立重复来进一步降低这一上界[p5, section 3]。GVFA 采用高斯随机投影，在保持单轮 $O(n^2)$ 复杂度的同时，使精确算术与连续高斯采样下对固定非零错误的单轮漏检概率降为零，并给出浮点不确定性模型下的漏检概率上界。
- 本项目要用的机制：对 $A,B,C\in\mathbb R^{n\times n}$，用同一个标准高斯随机列向量 $\omega$ 比较 $C\omega$ 与 $A(B\omega)$，不重新计算完整的 $AB$；若重复验证，每轮重新独立采样，全部通过才接受。本文“漏检”指错误结果被接受；浮点程序的“通过”仅表示在指定阈值内未发现不匹配.

## 核心公式与算法

| 论文位置 | 内容 | 说明 |
|---|---|---|
| p.5, §3，Algorithm 1，及随后一段 |**经典Freivalds算法：** 随机生成向量 $\omega\in\{0,1\}^n$，各分量相互独立且等概率取 0 或 1；使用同一个 $\omega$，依次计算 $y=C\omega$、$t=B\omega$ 和 $z=At=A(B\omega)$。比较 $y$ 与 $z$：不相等则拒绝，相等则本轮通过。|精确算术下，正确乘积必然通过；错误乘积的单轮漏检概率不超过 $1/2$。每轮重新独立采样，全部 $k$ 轮通过才接受，漏检概率不超过 $2^{-k}$。每次矩阵向量乘法计算 $n$ 个长度为 $n$ 的点积，每个点积需要 $n$ 次乘法和 $n-1$ 次加法，因此三次矩阵向量乘法共需 $3n[n+(n-1)]=3n(2n-1)$ 次运算。再加上随机向量生成和比较的 $O(n)$ 开销，单轮时间复杂度为 $O(n^2)$，重复 $k$ 轮为 $O(kn^2)$。|
| pp.5–6，§4.1，Algorithm 2 及随后一段；p.7，Theorem 4.3 开头；p.9，§4.5 | **高斯变体 GVFA：** 将二进制随机向量换成高斯随机向量。本笔记采用 $\omega_j\overset{\mathrm{i.i.d.}}{\sim}\mathcal N(0,1)$，即各分量独立服从正态分布、均值为 0、方差为 1。每轮只采样一个 $\omega$，依次计算 $y=C\omega$、$t=B\omega$、$z=At$，再比较 $y,z$。 | Algorithm 2 允许独立但不必同分布的正态分量；这里选择标准正态，是为了与 Theorem 4.3 的概率分析一致。无需计算完整的 $AB$。原文给出三次矩阵向量乘法共 $3n(2n-1)$ FLOPs；采样和比较另需 $O(n)$ 工作，单轮仍为 $O(n^2)$，其中采样成本按每个随机数均摊为常数量级计。 *(i.i.d. 即 independent and identically distributed)* |
| pp.6–7，§4.2，Theorem 4.2 及证明 | **精确算术下的漏检概率：** 令 $\Delta=AB-C$，则两侧投影之差为 $g=A(B\omega)-C\omega=\Delta\omega$。若 $\Delta=0$，验证必然通过；若 $\Delta\ne0$，标准高斯向量满足 $\Delta\omega=0$ 的概率为零（零测度），即 $\Pr(\Delta\omega=0)=0$。 | 漏检要求随机向量恰好落入差矩阵的零空间。非零差矩阵的零空间维数小于 $n$，相当于高维空间中的一个低维集合，**连续**高斯抽中它的概率为零。这不表示不存在导致漏检的向量，也不表示实际程序永不漏检；定理只针对固定的矩阵、连续高斯与精确算术。|
| p.7，§4.3，Theorem 4.3 证明中单个分量的分析 | **单个残差分量的分布：** 对 $g=\Delta\omega$，有 $g_i=\sum_{j=1}^{n}\Delta_{ij}\omega_j$。其均值为 0，方差为 $\tilde\sigma_i^2=\sum_{j=1}^{n}\Delta_{ij}^2$，因此 $g_i\sim\mathcal N(0,\tilde\sigma_i^2)$。若 $\tilde\sigma_i>0$，则 $\Pr(\lvert g_i\rvert\le\epsilon)=2\Phi(\epsilon/\tilde\sigma_i)-1$。 | $\tilde\sigma_i$ 是标准差，也就是差矩阵第 $i$ 行的二范数；$\Phi$ 是标准正态累积分布函数。该概率表示“这一分量的偏差没有超过阈值”。若该行全零，则 $g_i$ 恒为零，通过概率为 1。原文标准化时写成除以方差 $\tilde\sigma_i^2$，应除以标准差 $\tilde\sigma_i$；此处已明确修正。 |
| pp.7–8，§4.3，Theorem 4.3 及证明，至证毕符号处 | **考虑浮点误差的漏检上界：** 对固定的 $\Delta\ne0$ 和 $\epsilon\ge0$，论文研究所有残差分量都落在阈值内的概率：$p_\epsilon=\Pr(\max_i\lvert g_i\rvert\le\epsilon)$。令 $\tilde\sigma=\max_i\tilde\sigma_i$，则 $p_\epsilon\le2\Phi(\epsilon/\tilde\sigma)-1$。 | 所有分量同时通过的概率，不会高于其中任意一个分量通过的概率；选取标准差最大的分量，可得到这里的最小单分量上界。这一步不要求不同 $g_i$ 独立。$\Delta$ 和 $\tilde\sigma$ 仅用于理论分析，验证时不需要先算出来。原文随后在独立分量情形中推导更强上界时写反了不等号，本文不采用文中加强结论。 |
| p.8，§4.3，条目 (i) 及随后的小参数积分讨论 | **误差大小与漏检概率：** 标准正态密度在 0 处最大，因此对 $a\ge0$，$2\Phi(a)-1\le\sqrt{2/\pi}\,a$。结合上界可得 $p_\epsilon\le\min\{1,\sqrt{2/\pi}\,\epsilon/\tilde\sigma\}$；当 $\epsilon/\tilde\sigma$ 很小时，正态区间概率可用这个线性表达近似。 | 比较阈值固定时，故障使差矩阵最大行二范数越大，这个漏检上界越小；故障偏差固定时，阈值越大，上界越大。与 1 取最小值是本文补充整理以增加严谨性；原文小参数解释中再次出现除以方差的写法，这里统一按标准差修正。 |
| p.8，§4.3，条目 (ii)；p.9 开头的优点 (ii) | **独立重复验证：** 固定 $A,B,C$、分布和判定规则，每轮重新生成独立的高斯向量。任一轮不通过就拒绝，只有全部 $k$ 轮通过才接受。若单轮漏检概率为 $p$，最终漏检概率为 $p^k$；若只知道 $p\le\bar p$，则最终上界为 $\bar p^k$。 | 随机向量的生成应独立于输入矩阵；重复使用同一个向量不能获得 $p^k$ 的保证。实现时在循环外初始化一次随机数生成器，再连续取样，不要每轮用同一 seed 重置它。重复 $k$ 轮的最坏时间为 $O(kn^2)$；论文没有给出适用于所有输入的固定重复次数。 |
| p.6，§4.2 首段；pp.7–8，§4.3 | **实际浮点程序的判定：** 用带帽符号表示已舍入的计算结果：$\hat y=\operatorname{fl}(C\hat\omega)$、$\hat t=\operatorname{fl}(B\hat\omega)$、$\hat z=\operatorname{fl}(A\hat t)$，再计算 $\hat r=\operatorname{fl}(\hat z-\hat y)$。可采用统一绝对阈值条件 $\max_i\lvert\hat r_i\rvert\le\tau$ 判定本轮通过。 | **具体浮点判定阈值及其选取方法，论文未给出**。原文研究的是理想残差 $g$ 的不确定性，而程序比较的是含舍入误差的 $\hat r$。不能直接将 FP32 的 $2^{-23}$ 或 FP64 的 $2^{-52}$ 当作任意输入的绝对阈值，也不能直接把 $\epsilon$ 换成 $\tau$ 就声称获得理论保证。`tau` 应显式提供；通过只表示阈值内未发现不匹配。 |
| p.9，§4.4，Algorithm 3 及随后一段 | **双向 GVFA：** 生成相互独立的高斯行向量 $u^T$ 和列向量 $v$，同时比较 $u^TC$ 与 $(u^TA)B$，以及 $Cv$ 与 $A(Bv)$。对于单个错误元素，左侧检查的不匹配位置指出错误列，右侧检查的不匹配位置指出错误行。 | 需要六次矩阵向量乘法、两次向量比较，主要乘加开销为 $6n(2n-1)$，单轮仍为 $O(n^2)$；操作数由原文六次乘法展开。原文将两个向量的行、列称呼写反，此处按乘法维度统一。若左右漏检概率分别为 $p_L,p_R$，且两侧采样独立，则同时漏检概率为 $p_Lp_R$；两侧都有共同上界 $p$ 时，才可统一写为不超过 $p^2$。这是对原文 $p^2$ 表述的条件说明。 |
| p.9，§4.5 | **融合乘加（FMA）实现：** FMA 将 $a\leftarrow a+b\times c$ 合并为一次指令，并只进行一次舍入。GVFA 的矩阵向量乘法包含大量这样的乘积累加，可使用支持 FMA 的硬件实现。 | 相比乘法、加法分开执行，FMA 有望提高性能并减少局部舍入误差。论文没有提供实测加速比、检测率提升或使用 FMA 后的阈值公式。、|
| p.10，§5，矩形矩阵与连乘扩展段 | **矩形矩阵与多矩阵乘积扩展：** 若 $A\in\mathbb R^{m\times p}$、$B\in\mathbb R^{p\times n}$、$C\in\mathbb R^{m\times n}$，仍可用 $\omega\in\mathbb R^n$ 比较 $C\omega$ 与 $A(B\omega)$。对 $N$ 个矩阵的连乘，可从最右端依次乘到向量上，再与候选乘积的投影比较，共需 $N+1$ 次矩阵向量乘法。 | 矩形情形中，$B\omega$、$A(B\omega)$、$C\omega$ 分别需要 $O(pn)$、$O(mp)$、$O(mn)$，总计 $O(pn+mp+mn)$。原文写成 $O(mp+np)$，遗漏了 $C\omega$ 的开销，这里明确按实际步骤修正；连乘的成本还取决于各矩阵尺寸。 |
## 伪代码

```text
函数与符号说明：
    以下是便于描述算法的伪代码记号，不是论文规定的函数名。
    D / dtype：数据类型；本文 D 为 float32（FP32）或 float64（FP64）。
    Scalar[T]：一个类型为 T 的值；bool 表示真假，int 表示整数。
    Tensor[D, shape]：类型为 D、形状为 shape 的数组。
        (n,n) 表示 n 行 n 列矩阵，(n,) 表示长度为 n 的向量，() 表示标量。
    <-：赋值，将右侧结果存入左侧变量；@ 表示矩阵乘法。
    rng：随机数生成器；seed 是初始化它的种子，用于复现采样序列。
    rng.standard_normal(n)：生成 n 个标准正态随机样本，组成长度为 n 的向量。
        本文约定返回 float64 数组；每次调用继续取新样本，不重置生成器。
    cast_D(x)：将 x 转换为数据类型 D，形状不变；转换可能产生舍入。
    MATVEC_D(M,x)：计算矩阵 M 与向量 x 的乘积；乘法、累加和结果存储均使用 D。
    SUB_D(z,y)：逐元素计算 z-y，并将每个结果舍入为 D。
    round_D(x)：将数值 x 舍入为 D；取最近的可表示值，恰好居中时取末位为偶数者。
    abs(r)：逐元素取绝对值；max(abs(r)) 表示所有分量中最大的绝对值。
    NaN / Inf：非数值结果／无穷值；出现这些值时，本文规定报数值异常。
输入：
    A, B, C : Tensor[D, (n,n)]，n >= 1，D ∈ {float32, float64}
              三者 dtype 相同；分别对应 FP32 或 FP64，不做隐式类型转换。
    tau     : Scalar[D]，有限且 >= 0；绝对比较阈值，必须显式提供，无默认值。
    k       : Scalar[int]，k >= 1；取 k=1 即单次验证。
    rng     : 已初始化的有状态随机数生成器；支持 standard_normal(n)，
              返回形状 (n,) 的 float64 标准正态样本，并前进内部状态。
输出：
    passed       : Scalar[bool]，是否所有已要求的轮次均在阈值内通过。
    rounds_run   : Scalar[int]，实际运行轮数。
    residual_inf : Scalar[D]，最后执行的一轮的最大绝对残差。
步骤：
    # 数学运算来源：Alg.2，p.277；独立重复来源：§4.3(ii)，p.280。
    # dtype、RNG 接口、tau、诊断输出和异常行为是本文实现约定；论文未指定。

    1. 检查矩阵形状、共同 dtype D、n>=1、k 为正整数；
       检查 A,B,C 全为有限值，tau 的 dtype 为 D 且有限、非负。
       参数非法则报错，不进入验证。

    2. 对 j = 1,...,k：
         omega <- cast_D(rng.standard_normal(n))   # (n,), D；本轮新采样
         # 同一轮只取一个 omega；不归一化、不裁剪。
         # rng 在循环外初始化一次，禁止每轮重新设置相同 seed。

         y <- MATVEC_D(C, omega)                   # (n,), D
         t <- MATVEC_D(B, omega)                   # (n,), D
         z <- MATVEC_D(A, t)                       # (n,), D；不计算 A @ B
         r <- SUB_D(z, y)                          # (n,), D

         若 omega,y,t,z,r 任一含 NaN/Inf：报数值异常，不能返回“通过”。
         residual_inf <- max(abs(r))               # (), D
         若 residual_inf > tau：
             返回 (False, j, residual_inf)         # 任意一轮不通过就停止

    3. 返回 (True, k, residual_inf)                 # 全部轮次通过

    # MATVEC_D(M,x)：按下述固定顺序计算参考版本，每个操作均舍入到 D：
    #   对每一行 i：s = round_D(M[i,0] * x[0])
    #   对列 q=1,...,n-1：s = round_D(s + round_D(M[i,q] * x[q]))
    #   将 s 写入输出第 i 项。输出形状 (n,)，dtype 为 D。
    # SUB_D：逐元素相减并舍入到 D。
    # round_D：round-to-nearest, ties-to-even；此参考顺序不融合为 FMA。
    # 固定顺序和舍入约定由本文补充；原文 §4.5 p.281 未规定具体 kernel。
```

## 复现要点

- 需要的输入统计量：基础验证只需要 $A,B,C$、尺寸、dtype、随机数生成器和阈值，不需要预计算均值、方差、校验和、$AB$ 或 $\tilde\sigma$。其中 $\tilde\sigma$ 仅用于理论上界分析；如果另行设计自适应阈值，需要哪些范数或尺度统计量，论文未给出。
- 超参数与取值：
  - 数据类型 `dtype`：FP32 或 FP64。
  - 验证次数 `k`：正整数；`k=1` 表示单次验证，论文未给出固定推荐值。
  - 判定阈值 `tau`：非负数；论文未给出具体取值或选取方法。
  - 随机种子 `seed`：整数，用于复现实验，论文未指定。
  - 随机向量分布：各分量独立服从标准正态分布 $\mathcal N(0,1)$，每轮重新采样。
- 阈值或判定条件：精确算术检查 $A(B\omega)=C\omega$；本文浮点版本检查 `max(abs(r)) <= tau`。**具体可执行浮点阈值及其选取方法，论文未给出**。§4.3 提到 FP32 的 $2^{-23}$ 和 FP64 的 $2^{-52}$，但没有把它们推导为与矩阵维度、数据尺度和乘加误差相适应的绝对阈值。`tau` 可待后续通过专门误差分析或独立无故障数据校准确定；这些均是待讨论方案，后者只有经验意义。通过不等于证明乘积精确正确；若阈值未校准，超阈值也可能来自正常舍入。
- 论文的实验设置：**论文未给出任何实验设置和实验数据，仅有理论分析**。
