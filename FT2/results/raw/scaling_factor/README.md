# FT2 scaling factor 缩减实验结果

## 结论

- 建议 RTX 4090 上的默认 scaling factor 仍为 **2.0**。
- 本轮所有受保护档位的 SDC 都在 0–1/400 之间，统计上不能认为它们彼此有差异。
- factor=2.0 相比 1.0–1.5 大幅减少对正常激活的额外截断，同时保持了几乎相同的故障检测率。
- factor=2.5 虽然在本次抽样中是 0 SDC，但与 factor=2.0 只相差 1 个样本，配对检验 p=1.0，不能将它解读为更优。

## 实验范围

- 模型/数据集：Qwen2-Math-7B / GSM8K
- 故障类型：FP16 exponent-bit fault
- scaling factor：1.00、1.25、1.50、1.75、2.00、2.25、2.50
- 10 个 prompt，每个受保护档位共用同一组 400 个冻结故障规格
- 逻辑上共 3200 个故障运行；复用主实验的 no-protection 和 factor=2.0，新运行 2400 个故障样本及 60 个干净对照
- 新推理用时约 6.82 小时
- 固定贪心解码 180 tokens，评分使用作者仓库的 reference-token recall 逻辑，不使用 clean-evaluability gate

60/60 个新干净对照和逻辑上 80/80 个全部干净对照均能正确作答。所有受保护档位相对 factor=2.0 的精确 McNemar 检验均为 p=1.0。

## 解读与缩减规模建议

400 个共用故障规格/档可作为 RTX 4090 上的确认性缩减规模：它足以显示无保护到 FT2 保护的大幅改善，也能观察不同 factor 对截断强度的影响。但由于受保护后 SDC 只有 0–1 例，它不足以对 0.25% 级别的差异进行排名。因此推荐 factor=2.0 的依据是“SDC 已进入相同低水平，同时减少过度截断”，而不是声称其抽样 SDC 绝对最低。
