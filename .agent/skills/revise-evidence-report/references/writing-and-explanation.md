# Writing and Explanation

Use stable guidance. Apply task-specific preferences within the report or its decision log rather than changing this reference.

## Order information for the reader

- State the report purpose, evaluated object, approach, key finding, and evidence boundary early.
- Give each section one clear responsibility and use parallel evidence depth for parallel sections.
- Lead with the finding, judgment, or action; follow with the necessary evidence and qualification.
- Put the integrated conclusion near the end and keep it consistent with the opening summary.
- Move record IDs, long paths, hashes, version inventories, and detailed audit routing to an appendix.

## Write with evidence density

- Use concrete nouns, explicit subjects, and one main idea per sentence.
- Distinguish observed facts, derived results, interpretation, current capability, proposal, and limitation.
- Place definitions, denominators, exclusions, uncertainty, and limitations where they constrain the result.
- Remove navigation prose, repeated scope statements, promotional claims, and conclusions that add no information.
- Use tables for three or more objects with stable comparison dimensions; keep prose for explanation and judgment.
- Preserve machine-readable tables as tables rather than images.

## Maintain source traceability

Name methods, systems, datasets, and components in prose. Use source tags for traceability rather than as substitutes for content. Split a sentence when its independent facts need different sources. Remove obsolete source tags when deleting a claim.

Describe what a source studied, how it did so, what it found, and where it applies. Keep supporting, limiting, and contrary evidence visible when they materially affect interpretation.

## Explain metrics

Define each unfamiliar metric at first use or in a concise metric glossary:

1. what it measures;
2. how it is computed;
3. its unit, range, or reference point;
4. what higher, lower, zero, positive, or negative values mean;
5. how the report uses it;
6. its interpretation limits.

Explain a metric in terms of the actual observation unit and denominator. Keep missing and non-finite states distinct from zero.

## Explain cases and trajectories

Start with what happened, the key measurement, and the supported inference. Preserve individual observations when aggregation would hide important variation. For a sequence, describe the intervention or reference point, immediate change, peak or interval behavior, final state, and missing observations. Keep internal record identities in source tags or appendices unless readers need them to compare cases.
