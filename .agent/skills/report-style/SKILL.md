# 报告语言风格

以下规则用于各类报告，也用于直接发给用户的进展说明和工作总结。内容、结构和文件格式遵循用户要求。

## 表达

- 开头直接说重点：当前进展、结果、问题或建议，再补充必要原因和细节。
- 使用短句和常用词，写清谁做了什么、结果怎样。拆开多层转折、因果和修饰，保留句子之间的联系。
- 语气专业、平实。日常报告直接自然，正式报告严谨克制；必要术语简短解释。
- 用具体动作和事实代替空泛评价，省去“全面赋能”“深度剖析”“具有重要意义”等没有新增信息的套话。
- 直接说明做法及目的，避免反复使用“不是……而是……”等对比句式，也不堆砌自造术语和抽象名词。
- 省去审计过程、来源追踪和泛泛的适用范围说明。影响理解的条件或不确定性，在相关句子中简短说明。
- 润色保留事实、数值和原有确定程度，准确表达已经完成、计划开展和推测的内容。

## 组织

- 每段围绕一个意思，按原因、行动、结果等实际关系衔接，删去重复总结和机械过渡。
- 短报告优先使用自然段；并列事项用列表，需要对照时用表格。较长报告再按主题设置标题，避免多层编号。
- 用户提供结构时沿用原结构。细节写到读者能够理解和行动为止，避免为了简短省略关键解释。
